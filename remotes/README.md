# Remote backends

The UI uses a common command vocabulary while each backend translates commands to the TV platform.

Current implementation:
- LG/webOS: `lgtvremote-cli`

Planned platform-specific backends:
- Samsung/Tizen
- Sony/Android TV or Google TV
- Philips/Android/Google TV or model-specific platform
- Panasonic/model-specific platform
- Toshiba/model-specific platform
